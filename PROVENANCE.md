# Provenance and scope

This repository provides a zero-dependency Node.js 24 CLI for bounded, resumable API batch searches with SQLite state persistence and provenance-preserving CSV exports.

- Bundled fixtures use reserved `.test` domains and synthetic queries; no external credentials, live leads, or third-party API payloads are shipped.
- Built on Node.js built-in `fetch`, `node:sqlite`, and `node:test`.
- Original source code and documentation are published under the [MIT License](LICENSE). PublicWWW is a third-party service whose account and API terms remain separate.

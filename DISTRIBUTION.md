# Distribution scope

This is the 0.1.0 API-to-CSV personal work sample. Runtime, fixtures and tests are unchanged from the accepted implementation; this distribution updates licensing and presentation only.

It provides a command-line workflow and Windows launchers, with editable input files, bounded pages/attempts, SQLite progress and two CSV views. It ships invented `.test` examples, not useful leads or buyer inputs. Provider account entitlement, actual search semantics and live results require separate verification before real use.

Forty-three maintained tests passed on Windows and Ubuntu for this runtime/test source. They cover process interruption and retry recovery, loopback failures, partial coverage, CSV safety and snapshot exports. This does not establish power-loss durability, universal data correctness, a standalone GUI, enterprise integration or client savings.

AI assisted implementation and documentation. No paid contract or client outcome is represented. MIT applies to the original source/documentation; no third-party service access is included. Existing personal webhook and MCP projects remain separate.
